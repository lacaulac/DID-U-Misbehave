# DID-U-Misbehave

The paper is [available on HAL](https://hal.science/hal-04957256/document) for detailed explanations about the behaviours used in this dataset as well as other important information regarding the overall contribution.
The mapping between behaviour names and the numbers that represent them in the penultimate column of the dataset is the following:

|Class name|Number|
|-|-|
|NEUTRAL|0|
|CMD_EXEC|1|
|FILE_READ|2|
|FILE_WRITE|3|
|COPY|4|
|NET_COMS|5|
|SYS_INFO|6|
|FS_INFO|7|
|NET_INFO|8|
|FS_OP|9|
|ARG_FILE|10|
|NET_CFG|11|
